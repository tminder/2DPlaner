Prototype 16: parent-child placement (containment)

Tests D-032's "inside" placement mode: connection child parent { placement: "inside" } constrains a child to stay within its own parent's boundary when dragged, sliding along the boundary (via the parent's nearest edge, reusing D-041's contact-normal/tangent-slide approach) rather than freezing outright. Drag "sofa" around inside "room" — it should never be draggable outside the room rect, and should slide along a wall if you keep pushing past it.

Scope of this test: containment only, no flush combinable addition (D-032's door-in-wall half) — that's a separate, not-yet-built piece. Only a rect child with a plain literal position is supported, dragged against a rect/polygon parent; no corner-refs, no other connections, no self-intersection checking. A standalone local test, not wired into docs/.
