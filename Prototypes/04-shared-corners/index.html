2DPlaner prototype: shared corners + hover states

Throwaway prototype for D-018 (points as node references / shared corners), building on 03-drag-sync. wall_a, door and wall_b no longer duplicate their shared endpoint coordinates — they reference the same corner_1/corner_2 nodes. Two hover states: hover an object (a rect or a wall's own body) to see it glow blue — dragging it moves that object's own data. Hover a corner (small dot, per D-016) to see it glow red, along with every line that references it turning red too — a preview that dragging this single node will move all of them, since they share the exact same coordinate.

Known simplifications: this prototype does not implement Connections (D-014) at all — it's exploring whether shared corner-nodes can replace what 03 was using Connections to approximate for the "these touch at exactly one point" case. A line with an endpoint pinned to a corner can't have that endpoint dragged directly (you get a message telling you to drag the corner instead) — only the corner itself moves a shared point.
