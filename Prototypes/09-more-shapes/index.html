2DPlaner prototype: pentagons, bent lines, circles

Answers "can we make other shapes?" — mostly with things that already worked without anyone showing it. Pentagon: garden_bed is a polygon with 5 corner nodes instead of 4 (see 05) — the renderer, the self-intersection check (F-004), and dragging never assumed exactly 4; they all just iterate however many points are given. Line with multiple nodes: path is a line whose 4 points are each their own node (path_1.. path_4), the same points-as-node-reference mechanism as the pentagon's corners — drag any one of them to reshape just that segment, not the whole path. That works on an open line exactly as it does on a closed polygon; nothing about the mechanism was ever specific to closed shapes. Circle: fountain is genuinely new — no shape kind for a circle existed before this prototype.

Try dragging any of the 5 garden-bed corners (deforms the pentagon, exactly like 05's rectangle-turned-quadrilateral), any point of the path (reshapes that segment), or the fountain itself (just drags — it's a plain node with a position, same as any other draggable node, so nothing about drag-and-drop needed to change for a new shape kind).

What the circle addition actually required: one new branch in the renderer (shape: "circle" reads a radius property and draws an SVG <circle>), plus fixing the viewBox's bounding-box calculation to account for a circle's radius (it previously only ever looked at node positions, which happened to work for polygons/lines since every vertex is its own node with its own position — a circle has no such second point, so its edge was invisible to the auto-fit camera without this fix). Drag, hover, and everything else needed zero changes — they only ever cared about position, never about what shape a node renders as.
