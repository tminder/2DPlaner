Modules

Community modules

A module extends a plan with new rendering, new interactivity, or a reusable higher-level building block — loaded straight from a URL with module "<url>". This page lists modules other authors have published.

Third-party code — read it before you trust it A listed module is someone else's code, not covered by Planagonia's own license. It runs unsandboxed, with the same access to the page any script would have — the app still asks you to confirm before loading one it hasn't seen before, and that's worth taking seriously here too.

Submitting a module

Built a module you'd like listed here? Open a pull request against this page on GitHub, adding a card with its name, a one-line description, the module "<url>" line to load it, and a link back to its own source — or email info@planagonia.com and it'll get added by hand.
