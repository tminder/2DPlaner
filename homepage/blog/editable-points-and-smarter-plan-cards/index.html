Product update

Editable Points, Quicker Renames, and Smarter Plan Cards

October 7, 2026

Three updates that all point the same direction: fewer trips back to the code for things that are really just clicks on the canvas — reshaping a line or a room point by point, renaming something or giving it a different look, and cleaning up your own saved plans without opening each one first.

A shape's own points, fully in your hands

Every corner of a polygon or polyline has been draggable for a while — but only the corners that already existed. There was no way to add a new one along an edge, or remove one you no longer wanted, without going back into the code and editing the point list by hand. Not anymore. Select a shape and a small handle now appears at the midpoint of every edge — click it, and a new point appears exactly there, ready to drag like any other. Right-click an existing point instead, and it offers to delete it, one entry removed from the list, nothing else disturbed.

An open line (a wall, a pipe, anything drawn as a polyline rather than a closed shape) gets one more trick: a handle at each of its two open ends. Click one, and the line grows a little further in the same direction, continuing its own last segment rather than guessing at some arbitrary length. It's the natural other half of adding a point along an edge — one grows a line from the middle, the other from the tips.

Both respect something the editor has cared about since parcels could share a corner (see the Electrical Grid example in the app): if a point you're deleting — or extending from — happens to be a corner that another shape also uses, that shared corner is never touched. Only your own shape's own point list changes.

Rename and restyle without opening the code

Right-clicking any element already offered Duplicate, Delete, and a few other actions. It now has an "Edit" group with two more: Rename, which sets the element's own display label through a plain text prompt instead of a line of code, and Change Style, which lists every style preset your plan already declares so you can swap one on with a click — the exact style currently applied shows up checked, so you always know where you stand.

Manage a saved plan from its own card

The "My plans" picker has always let you click a card to switch to that plan. Now you can right-click one instead — or hold it down on a touchscreen — for Duplicate or Delete, acting on that plan without switching to it first. Useful the moment you're keeping a few variations of the same layout side by side and just want to clear out an old one, or spin off a copy to try something risky, without losing your place in whatever you're actually working on.

Want to try any of this? Open the app — everything above is already live, no update needed on your end.

None of these change what you can build, exactly — they change how much of it you can do without ever touching the code at all.
